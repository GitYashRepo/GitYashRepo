# GitYashRepo GitHub Profile Kit

## Files
- `README.md` — copy this into the root of `GitYashRepo/GitYashRepo`.
- `assets/hero-banner.svg` — custom banner shown at the top.
- `assets/profile-placeholder.svg` — optional placeholder illustration; it is not currently inserted in the README. Replace with your own photo if you want a portrait.
- `assets/projects/*.svg` — designed illustrative project thumbnails. These are not screenshots of your live websites.

## Install
1. Open https://github.com/GitYashRepo/GitYashRepo
2. Upload `README.md` to the repository root, replacing the current file.
3. Upload the entire `assets` folder to the same repository root, preserving the folder/file paths.
4. Commit the changes to the default branch.
5. Open https://github.com/GitYashRepo and check the Overview tab.

## Replace the placeholder project visuals
For the most authentic result, take screenshots of each live project and replace the SVG project preview files with real PNG/JPG screenshots. If using raster screenshots, update the corresponding `src="assets/projects/name.svg"` in README.md to `.png` or `.jpg`.

## Important
- Repository must be public and named exactly `GitYashRepo` under the `GitYashRepo` account.
- The stats cards, skill icons, and activity graph use third-party services and can occasionally be rate-limited or unavailable.
- Restra Menu's public URL was not supplied, so its card links to an email inquiry rather than inventing a live demo.
- `profile-placeholder.svg` is provided as an optional asset only. The README does not pretend it is your actual photo.
